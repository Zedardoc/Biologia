# 🧬 Proyecto Biología

¡Bienvenidos al repositorio del proyecto **Biología**!

---

## 🚀 Cómo empezar

Para comenzar a editar el proyecto, ejecuta el siguiente comando en tu terminal:

```bash
git clone https://github.com/Zedardoc/Biologia
```
Una vez clonado el repositorio, puedes comenzar a editar cualquier parte del proyecto, excepto las scenes por el momento.
